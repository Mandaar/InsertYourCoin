Sécurité SSL / antivirus

Sur une machine où un antivirus (souvent Avast) intercepte le HTTPS, Python peut échouer avec CERTIFICATE_VERIFY_FAILED. La solution propre est le paquet truststore (déjà dans requirements.txt) qui utilise le magasin de certificats de l'OS.

Ne jamais désactiver VERIFY_SSL. Le mettre à False n'est pas une correction : c'est un trou de sécurité qui expose les échanges à une interception. Il reste à True sur cette machine.

Risque & non-conseil

Cet outil est un instrument de recherche. Aucun gain n'est promis ni garanti. Le trading crypto peut faire perdre la totalité du capital engagé. Ceci n'est pas un conseil en investissement : les décisions et le risque appartiennent entièrement à l'utilisateur. Performances passées ≠ performances futures.

Pour l'installation complète, voir le fichier SETUP.md du dépôt.
